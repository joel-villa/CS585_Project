# Non-Internet Based Communication

## Project Goals:
	1. Compilation of emergency (non-internet intensive) text
	2. Inhouse testing of things 
	3. Educate the class on how to use mesh or some other form of
	  communication. With the goal of answering the following questions:
		- What is mesh (or other method)?
		- How expensive is the hardware? 
		- Where to buy?
		- How to setup?
		- **How to ensure privacy/security?**
			- Is it encrypted?
			- How to know when data is recieved? Do you care?
			- Handshake
		- What is the range on this? 
		- What kind of information/files can be sent?
		- Why would this stay up, in a scenario when the internet goes
		  down?
